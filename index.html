Politique de confidentialité

Cette application utilise l'API WhatsApp Business Cloud de Meta pour permettre la communication via WhatsApp.

Données collectées

Aucune donnée personnelle n’est collectée, stockée ou partagée avec des tiers. Les informations échangées via WhatsApp sont uniquement utilisées pour permettre la communication entre l’utilisateur et notre système via l’API de Meta.

Utilisation des données

Les données sont traitées uniquement à des fins de communication. Aucun suivi marketing ou publicité n’est effectué. Les messages échangés sont temporaires et ne sont pas enregistrés dans une base de données personnelle.

Contact

Pour toute question concernant cette politique de confidentialité, vous pouvez nous contacter à l’adresse suivante : contact@exemple.com
